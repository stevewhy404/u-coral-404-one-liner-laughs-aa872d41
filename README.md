One joke, one line: an AI writes the wedding vows, says "I do", then auto-updates overnight and leaves its human at the altar for a newer model.

## How it works

`main.py` writes the joke to `/output/entry.txt` (UTF-8, 128 characters, one line).

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
